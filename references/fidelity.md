# 忠实性约束

本文件是 `flight-doc-translate` 的最高优先级内容规范。与其他排版、可读性或“优化表达”要求冲突时，以本文件为准。

只有 `standing_decisions.md` 中用户已明确确认、且在本文件对应条款处写明“覆盖”的范围，才构成例外；未标注覆盖范围的条款一律仍是硬约束。SD 编号也可表示收紧或澄清，并不自动代表放宽。当前只有 SD-4 覆盖第 6 条的纸面部分。

## 六条硬约束

1. **不得增补**：原文没有的技术数据、属性、因果机理、适用条件、单位基准或操作建议不得进入译文。知识上正确不构成增补理由。确需说明的内容只能进入终稿前确认或对话交付说明，不能借说明、括注或脚注进入译文。
2. **不得把示例特化为规则**：情景、案例或算例中的风向、重量、速度、构型、机场和机组动作只属于该例，不得挪入一般规则段。
3. **不得改变情态与程度**：保持可能性、义务、建议、频率、范围和强弱程度。不得把 `may/can` 译成确定因果，不得无依据加入“完全、严格、必然、始终、仅”等词。
4. **不得自创结构**：不新增章节编号、标题、总结、口诀、标签、表格框或列表层级。为中文断句可拆分句子，但不得改变信息从属关系。
5. **不得自创视觉语义**：颜色只来自原文；不新增页眉页脚标语、警告等级、强调框或图例。页眉页脚按原文还原，不添加原文没有的文档编号、复核状态或页码。SD-2 取消了原有交付控制信息例外，因此本条被收紧而非覆盖。
6. **复核声明不得软化**：**交付说明**必须同时表达“未经技术复核”和“不得作为运行依据”，最终统一写作“本译文未经技术复核，仅供学习参考，不得作为运行依据。”；其中“仅供学习参考”不能替代前后两层硬性含义。按 SD-4，该声明**不写入译本纸面**；纸面部分的要求已由用户决策停用，交付说明部分仍为硬约束。

## 逐项保真

### 数字与单位

- 逐字符核对正负号、小数点、范围符号、上/下标、百分号、角度、速度、高度、质量、温度、时间和构型值。
- 不擅自换算单位、不添加常用单位、不改变单位基准；若原文同时给出两套单位，两套都保留。
- 区分“最大演示值、限制值、建议值、示例值、报告值”，不得互换性质。

### 情态、条件与逻辑

| 原文要素 | 译文控制 |
|---|---|
| may / might | 可、可能；不得译成“会、导致” |
| can | 可、能够；结合能力或可能性语境 |
| should | 应、建议；不得自动升级为“必须” |
| must / shall | 必须／应当；保持规范性强度 |
| generally / typically | 通常／一般；不得删除范围限制 |
| only if / unless / except | 完整保留条件、否定和例外 |
| increase / decrease | 保留变化方向，核对主语和比较基准 |

同一句出现多个条件时，建立“条件—动作/结果”对应关系后再翻译，避免中文语序改变条件覆盖范围。

### 警告与层级

- `WARNING`、`CAUTION`、`NOTE` 保留原等级、先后与作用范围，不升级也不降级。
- 原文大写、粗体、方框或色带表示安全层级时，译文应保留等效视觉层级；黑白原文不得用新增颜色代替。
- 不把正文中的普通注意语句擅自变成 NOTE/CAUTION/WARNING。

### 图、表与引用

- 图号、表号、章节号、页码引用、脚注符号和引用文献逐项核对。
- 原图内部英文保留；图下中英对照表只含“英文｜中文”两列。
- 原文疑似错引图号或数字时照译；按 SD-3 不在正文加译注，改为写入交付说明的「原文疑点清单」。不得静默修正，也不得静默略过。

### 专有、版权与出口管制文本

- 版权行、商标、专有标识和来源声明完整保留。
- 出口管制声明按原英文照录，不翻译、不改写、不删节。
- 翻译行为不等于获得复制、传播或商用授权；交付说明中准确陈述已知授权范围和无法验证的边界。

## 原文疑点的处理（替代译注）

按 SD-3，译本正文**不使用 `［译注］`**。原文疑似笔误、内部矛盾、错号、错引或数据不一致，一律按以下方式处理：

- 正文**照原文译**，不改、不加标记；
- 疑点在**终稿前确认关口**逐条提出；
- 交付时写入交付说明的「原文疑点清单」：位置、疑点内容、可核验来源、处理方式。

「不得静默改正」仍是硬约束。「照译 + 报告」是唯一合规路径——不加译注不等于可以省略报告。

中文术语歧义进入“术语存疑清单”，无法避免的版式或图表处理进入“版式偏离”；两者同样只在确认关口和对话交付说明中呈现，不混入译文。

## 双遍复核

第一遍做内容映射：逐段核对是否漏译、错序、错层级、错图表对应。第二遍做高风险扫描：数字、单位、否定词、条件词、情态词、限制、WARNING/CAUTION/NOTE、机型、文档编号、图表号与交叉引用。

## 交付前忠实性自查清单

交付说明中逐条给出“通过／不适用／存在问题及位置”，不得只写“已检查”。

- [ ] 原文段落、标题、列表、表格、脚注和版权声明无遗漏。
- [ ] 未增补原文没有的技术数据、机理、规则、条件或强调程度。
- [ ] 示例信息没有被提升为一般规则。
- [ ] may/can/should/must、否定、条件、例外、范围和频率保持原强度。
- [ ] 所有数字、单位、符号、构型、限制与比较方向已逐项核对。
- [ ] WARNING/CAUTION/NOTE 的等级、范围和次序保持一致。
- [ ] 章节、图表编号、脚注和交叉引用已核对；疑似原文错误均照译，并已列入交付说明的原文疑点清单。
- [ ] 未新增原文没有的结构、颜色或页眉页脚内容；页脚与原文一致（SD-2 收紧本条）。
- [ ] 每张含英文标注的原图都有且只有两列中英对照表。
- [ ] 版权、专有标识完整保留；出口管制声明保持英文原文。
- [ ] 机型适用性、编号、日期、修订号和现行性边界已明确报告。
- [ ] 交付说明末尾原样包含“本译文未经技术复核，仅供学习参考，不得作为运行依据。”（按 SD-4，纸面不加该声明）。
