# 第 6 章场景：着陆

## 适用场景

目视进近坡度指示、着陆几何、瞄准点、拉平与接地、跳着陆和中止／中断着陆、着陆滑跑、减速板、方向控制、刹车、反推、侧风着陆、低摩擦跑道和超重着陆。

## 高频句式框架

| English pattern | 中文框架 | 控制点 |
|---|---|---|
| initiate the flare at X | 在 X 开始拉平 | 不增加高度或目视条件 |
| adjust pitch attitude to X | 调整俯仰姿态以 X | 保留动作目的，不补写姿态值 |

## 易混边界

- `flare / flare mode` 分别是拉平动作和自动飞行显示方式。
- `firm touchdown / hard landing / bounced landing` 分别是坚定接地、重着陆和跳着陆。
- `rejected landing / balked landing` 在本对照资料中并列为“中止着陆／中断着陆”，其他来源须保留其定义差异。
- `main landing gear / main gear touchdown`、`nose landing gear / nose wheel touchdown` 分别是部件和接地事件。
- `speedbrake / spoiler / ground spoiler` 分别按操纵系统、部件和地面功能处理。
- `braking action / capability / force / pedal pressure` 分别是效应、能力、力和脚蹬压力。
- `reverse thrust / thrust reverser / reverse idle` 分别是推力、装置和位置。
- `crab / de-crab / sideslip / cross-control` 分别是偏流、消除偏流、侧滑和交叉操纵。
- `wet / slippery / contaminated runway` 分别是湿跑道、滑跑道和污染跑道，定义由当前来源决定。
