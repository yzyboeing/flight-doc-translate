# 第 7 章场景：机动飞行

## 适用场景

加速至和减速离开最大使用速度、发动机失效熟悉训练、高高度机动与抖振、快速下降、接近失速和失速改出、大坡度盘旋、地形避让、TCAS 交通／决断咨询、复杂状态预防及改出和风切变。

## 高复用句式框架

| English pattern | 中文框架 | 控制点 |
|---|---|---|
| initiate recovery at the first recognizable warning | 一识别出警告就开始改出 | 警告类型和时点必须照录 |
| reduce angle of attack | 减小迎角 | 不擅自增加操纵方式 |
| maintain control of the airplane | 保持对飞机的控制 | 不改写为保持姿态 |
| do not follow flight director commands | 不要跟随飞行指引仪指令 | 只适用于原文明确排除的机动 |
| monitor altitude and airspeed | 监控高度和空速 | 高 |
| limit bank angle if X | 如果 X，限制坡度角 | 保留条件和限制来源 |
| terrain clearance must be assured | 必须确保超障 | 不降低强制性 |
| TCAS issues a traffic/resolution advisory | TCAS 发出交通／决断咨询 | 区分 TA 与 RA |
| maneuvering is required when X | 当 X 时需要进行机动 | 保留触发条件 |
| recognize and confirm the upset | 识别并确认复杂状态 | 保留两个动作 |
| reduce automation | 减少自动操作 | 不自行指定脱开哪些系统 |
| return the airplane to normal flight | 使飞机恢复正常飞行 | 不补写具体改出步骤 |
| windshear may affect airplane performance | 风切变可能影响飞机性能 | 保留可能性 |

## 易混边界

- `rapid descent / expedited descent / normal descent` 分别是快速下降、加速下降和正常下降。
- `initial buffet / G buffet / stick shaker` 分别是起始抖振、“G”抖动和抖杆警告／装置。
- `approach to stall / stall / stall recovery / upset recovery` 分别是接近失速、失速、失速改出和复杂状态改出。
- `traffic advisory / resolution advisory` 分别是交通咨询和决断咨询，不能都笼统写成“TCAS 警告”。
- `terrain avoidance / traffic avoidance / windshear recovery` 的触发来源和机动目的不同。
- “复杂状态改出”是当前双语 FCTM 用法，不代表所有运营人或监管体系都采用这一中文名称。
