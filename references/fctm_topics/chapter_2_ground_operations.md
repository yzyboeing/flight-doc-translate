# 第 2 章场景：地面操作

## 适用场景

飞行前检查、静压孔和座舱压力设置、起飞简令、推出／拖行、滑行推力、滑行刹车、前轮转弯、狭窄区域转弯、恶劣天气滑行和单发滑行。

## 高复用句式框架

| English pattern | 中文框架 | 控制点 |
|---|---|---|
| use the minimum thrust required to X | 使用完成 X 所需的最小推力 | 不补写具体推力值 |
| allow time for airplane response before increasing thrust further | 进一步增加推力前，留出飞机响应时间 | 保留先后关系，不补写等待时长 |
| avoid riding the brakes | 避免持续带刹车 | 不译成完全禁止使用刹车 |
| slow to an appropriate speed before the turn | 转弯前减速到适当速度 | 不自行加入数值 |
| maintain clearance from X | 与 X 保持间隔 | 明确间隔对象 |
| use visual cues to determine X | 使用目视提示判断 X | 不把提示写成保证 |
| the main gear follows a path inside X | 主起落架沿 X 内侧的轨迹通过 | 保留转弯几何关系 |
| braking effectiveness may be reduced | 刹车效应可能降低 | 保留可能性 |
| if directional control becomes a problem | 如果方向控制出现问题 | 后续动作必须服从原文 |
| taxi with caution in X conditions | 在 X 条件下谨慎滑行 | 不补写本模块没有的程序 |

## 易混边界

- `pushback / towing / backing with reverse thrust` 分别是推出、拖行和用反推使飞机后退，不能互换。
- `nose wheel steering / rudder pedal steering / tiller` 分别指功能、脚蹬转弯和手轮装置。
- `brake heating / brake temperature / brake energy` 分别描述升温过程、温度状态和吸收能量。
- `engine-out taxi` 作状态表达时优先“发动机不工作滑行”；运行简称可按同一文档采用“单发滑行”。
