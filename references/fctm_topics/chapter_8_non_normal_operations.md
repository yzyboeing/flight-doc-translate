# 第 8 章场景：非正常操作

## 适用场景

非正常情况处理原则、飞行机组警戒、排故、就近合适机场着陆、增压／座舱高度、水上迫降、发动机与 APU、鸟击、撤离、飞行操纵、空速／高度不可靠、燃油、液压、起落架、超速、机尾触地、火警、风挡损坏以及超出非正常检查单范围的情况。

| English | 优先中文 | 使用边界 |

## 高频句式框架

| English pattern | 中文框架 | 控制点 |
|---|---|---|
| maintain airplane control | 保持飞机控制 | 非正常处置的主句，不补写操纵方式 |
| analyze the situation and take appropriate action | 分析情况并采取适当措施 | 不替换具体检查单 |
| accomplish the appropriate NNC | 完成相应的非正常检查单 | 不把检查单内容写入术语库 |
| do not troubleshoot unless X | 除非 X，否则不要排故 | 保留例外条件和否定范围 |
| land at the nearest suitable airport | 在最近的合适机场着陆 | 不把 `suitable` 省略成“最近机场” |
| time permits X | 时间允许时，X | 与“立即”或“尽快”区分 |
| X may indicate Y | X 可能表明 Y | 不把征兆写成确诊 |
| if the indication is unreliable, X | 如果指示不可靠，X | 后续措施必须来自待译原文 |
| compare X with Y | 将 X 与 Y 比较 | 保留比较对象 |
| use all available information | 使用所有可用信息 | 不自行列举未提供的信息源 |
| evaluate airplane handling | 评估飞机操纵性 | 不等同于完成适航检查 |
| consider the effect of X on landing | 考虑 X 对着陆的影响 | 不补写性能结论 |
| a malfunction may affect X | 故障可能影响 X | 保留可能性 |
| if damage is suspected, X | 如果怀疑有损伤，X | 不把怀疑写成已确认损伤 |
| the checklist does not address X | 检查单未涵盖 X | 不据此自行编制程序 |

## 易混边界

- `warning / caution / advisory / alert` 的等级和中文必须服从待译文件自身定义；本模块的“警戒”不可跨体系机械套用。
- `abnormality / malfunction / failure / inoperative` 分别偏异常情况、故障、失效事件和不工作状态。
- `troubleshooting / NNC accomplishment / memory step` 分别是排故、完成检查单和检查单中的记忆步骤。
- `nearest airport / nearest suitable airport` 不相等，不能省略“合适”。
- `jammed / restricted / inoperative / unreliable` 分别是卡阻、受限、不工作和不可靠。
- `fire warning / fire`、`cargo fire indication / confirmed fire` 必须保留证据程度。
- `flat tire / tire failure` 是否译“爆胎”取决于原文是否确认爆裂，不宜全局替换。
- 本模块只提供术语与句式，不得成为非正常操作或应急处置依据。
