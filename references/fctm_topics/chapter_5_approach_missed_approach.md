# 第 5 章场景：进近和复飞

## 适用场景

仪表和目视进近、高度表调定、进近简令与许可、稳定进近、最低标准、襟翼构型、复飞点、ILS／GLS、自动着陆、非 ILS 进近、VNAV／IAN／V/S、RNP AR、盘旋、目视起落航线、连续起飞着陆、复飞和一台发动机不工作进近。

## 高频句式框架

| English pattern | 中文框架 | 控制点 |
|---|---|---|
| brief the approach before X | 在 X 前完成进近简令 | 不补写简令项目 |
| verify the altimeter setting | 核实高度表调定 | 不把核实改成重新调定 |
| the approach should be stabilized by X | 进近应在 X 前稳定 | 时间／高度基准照录，不自行增加 |
| if the approach is not stabilized, go around | 如果进近未稳定，复飞 | 仅在原文确有该条件和动作时采用 |
| intercept the localizer/glideslope | 截获航向道／下滑道 | 区分信号束与一般航径 |
| remain on the vertical path | 保持在垂直航径上 | 不改写为保持下降率 |
| continue only if X is satisfied | 只有满足 X 时才可继续 | 保留必要条件和规范强度 |
| at the missed approach point, X | 到复飞点时，X | 不提前程序动作 |
| initiate the go-around | 开始复飞 | 与公布的复飞程序名称分开 |
| follow the missed approach procedure | 按复飞程序飞行 | 不补写程序内容 |
| visual reference must be maintained | 必须保持目视参考 | 保留强制性和持续性 |
| if visual reference is lost, X | 如果失去目视参考，X | 保留触发条件 |
| an engine failure on final approach may X | 最后进近时发动机失效可能 X | 保留时点和可能性 |

## 易混边界

- `go-around / missed approach` 都常译“复飞”，但前者偏动作、后者偏程序；标题并列时应保留并列结构。
- `localizer / glideslope / glide path / vertical path` 分别是航向道、下滑道、下滑航径和垂直航径。
- `radio altimeter / radio altitude` 分别指设备和测量值。
- `DA/H / AH / landing minima / MAP` 不得用“最低高度”笼统覆盖。
- `touch-and-go / stop-and-go / go-around after touchdown` 是三个不同训练或运行场景。
- `fail-passive / fail-operational` 必须服从当前文件定义；首次出现保留英文有利于技术复核。
