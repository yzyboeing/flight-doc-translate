# 来源权威与文体路由

本文件决定不同参考资料能够影响哪些翻译决策。术语库只能在等义范围内统一表达，不能覆盖当前待译英文的事实、条件、情态、否定、数字或适用性。

## 两条独立权威链

### 技术事实链

1. 当前待译英文及其定义、图表、警告和适用性；
2. 用户对当前任务的明确决定，但不得改变英文技术含义；
3. 同一文件内部可核实的交叉引用；
4. 可核实的现行权威资料。

任何中文参考资料都不能成为新增程序、数值、机型或限制的依据。

### 中文措辞链

1. 用户对当前任务确认且与原文等义的用语；
2. 同修订、同章节、同技术对象的双语对应；
3. 同一文档类型的已对齐用法；
4. 同场景但不同文档类型的已对齐用法；
5. 通用术语表或可核实的行业用语；
6. 保留英文并进入术语确认。

高层来源只决定其有权决定的事项。例如，同版中文 QRH 可以帮助确定检查单措辞，但不能改变当前英文检查单的动作顺序。

## 文档类型职责

| 文档类型 | 可优先决定 | 不得据此决定 |
|---|---|---|
| FCTM | 训练叙述、操纵方法、飞行阶段、建议和解释性表达 | QRH 动作顺序、法律义务、适航结论 |
| QRH | 检查单标题、控制件、目标状态、条件分支、记忆／参考／延迟项目、完成语句 | 扩展机理、训练理由、其他文件的程序 |
| FCOM | 系统名称、正常／非正常／补充程序用语及构型表达 | 当前英文没有的适用性或限制 |
| SOP | 经确认适用的机组分工、喊话和运营人表达 | 制造商事实、法规要求或其他运营人的做法 |
| 法规／适航文件 | 规范性、义务强度、法律术语和适用范围 | 训练偏好或运营人内部习惯 |
| 事故调查 | 证据强度、调查措辞、事实／分析／结论层级 | 运行程序或训练建议 |

不存在相应来源时，不创建空的文档类型模块。

## 对照状态

| 状态 | 判定条件 | 默认使用 |
|---|---|---|
| 已对齐 | 同修订、同章节、同对象，动作、条件和程度一致 | 同文档类型和同语境下可优先采用 |
| 等义对照 | 语序或句法调整，但技术含义、主体和逻辑一致 | 记录边界后采用 |
| 风格候选 | 只有中文来源，或双语版本／章节不能可靠对应 | 不作为无条件首选 |
| 冲突 | 可靠来源使用不同表达，且差异可能影响理解 | 保留并进入确认关口 |
| 废弃 | 已证实改变原意、混淆概念或错误扩大适用范围 | 禁止使用，并记录替代项 |

页数接近、文件名相似、同属一个运营人或具有相同主修订号，都不能单独证明条目已对齐。

## 同词跨文体规则

- FCTM 的 should / recommended / may 保持建议性或可能性，不因 QRH 常用祈使句而升级。
- QRH 的动作、目标位置、条件、分支和完成状态不得被 FCTM 的解释性语言稀释。
- 驾驶舱固定标签和模式名称原则上保留英文；受控双语资料明确给出稳定中文时，可在不妨碍识别的前提下采用中文并保留必要的英文标签。
- 同一英文词因动作／状态、控制件／系统、事件／结果而改变译法时，拆分为带语境条目，不做全局替换。
