# 印刷分发规格

仅当译本明确用于打印、装订或向飞行员纸面分发时执行。本文件不授予资料复制或传播权；版权与出口管制仍以原文和用户授权为准。

## 页面与装订

- 默认 A4 纵向；保留原版为 Letter 只有在用户明确要求且打印设备支持时采用。
- 建议页边距：上 18 mm、下 18 mm、外侧 16 mm、内侧 21 mm，装订线 5 mm。双面打印时在生成 buffer 后调用 `page_setup.js` 的 `patchMirrorMargins()`，并检查 `word/settings.xml` 含 `w:mirrorMargins`。
- 宽表只在确有必要时使用横向节；进入和退出横向节都要目视检查页码、页脚和空白页。
- 不为减少页数把正文字号压到 10.5 pt 以下；页数变化不是错误，但必须记录。
- 版权、专有标识、出口管制声明及其他法律／控制文字不得小于 7.5 pt；若原文更大则按原层级保留，不以缩小字号换取页数一致。

## 首页必须留在纸面上的控制信息

首页包含以下信息，不能只在聊天交付说明中出现：

1. 原文标题、文档编号、修订号、发布日期和机型适用性；
2. 译本生成日期与版本；
3. 醒目横幅：**未经技术复核，不得作为运行依据**；
4. 现行性状态：已由何种权威来源核验，或“无法独立核实现行版本”；
5. 原文版权、专有标识和授权条件；出口管制声明保留英文原文；
6. 版本块：原文文件名/编号、原文日期、译本版本、译者/生成方式、技术复核人（未复核时写“未复核”）、适用范围、版式偏离。

## 目录与逐页标识

- 文档超过约 8 页或原文自带目录时生成目录；目录只使用原有标题层级，不新增概括章节。
- Word 目录字段可能需用户打开文档后更新；交付前要在 LibreOffice/Word 渲染结果中确认显示内容合理。
- 每页页脚包含：文档编号｜未经技术复核；不得作为运行依据｜第 X 页 共 Y 页。
- 原文已有刊名、版权行、文档编号或页码时保留其信息，不以新页脚覆盖或删除；必要时把两者分行。

## 黑白打印检查

- 原文黑白：不加入颜色或灰底表头，依靠字重、线条和间距表达层级。
- 原文彩色但拟黑白打印：先生成灰度样张。若颜色承担分类、状态、方向或警告等技术语义，且转灰后无法可靠区分，默认建议彩色打印，并把该页标记为“不适合黑白分发”；不得为适应黑白打印而重配原图颜色或自创线型、纹理、图例和解释列。
- 只有原文已明确给出颜色名称或颜色—对象对应关系时，才可把该原文信息转写为文字标注；图内标注对照表仍只能是“英文｜中文”两列，不得增加第三列解释。所有转写均列入版式偏离记录。
- 图片保持足够分辨率。200 dpi 是一般技术插图起点；细线、微小标注或扫描页需要更高 dpi 时提高并重新检查。

## 打印前自查

- [ ] A4/Letter、方向、内外侧页边距和装订线符合实际装订方式。
- [ ] 首页横幅与版本块完整，纸面可独立判断“未经技术复核、不得作为运行依据”。
- [ ] 文档编号、修订号、日期、机型适用性和现行性边界可见。
- [ ] 目录层级与页码正确，无新增原文结构。
- [ ] 页脚逐页出现，页码连续，奇偶页内外侧视觉正常。
- [ ] 表格未被不合理拆分，标题行按需重复，无裁切或过小文字。
- [ ] 图、图题、图内标注对照表关系清楚；图像和细线打印可辨。
- [ ] 彩色页的黑白样张仍可读；不适合黑白分发的页面已标明，任何允许的原文颜色信息文字转写均已记录。
- [ ] 法律／控制文字不小于 7.5 pt，版权、专有标识和英文出口管制声明清晰可读。
- [ ] 版权、专有标识和英文出口管制声明完整。
- [ ] 已实际打印或生成打印 PDF 抽查首页、目录、宽表、彩图和末页。
