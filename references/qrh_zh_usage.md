# QRH 中文用法路由

本文件是 QRH 检查单结构、动作状态和系统表达的总入口。只在待译材料具有检查单、程序项目、控制件—目标状态或非正常处置文体时加载；训练解释性材料优先使用 FCTM 路由。

## 使用边界

- 当前英文 QRH 或待译英文始终决定标题、动作、条件、分支、顺序、目标位置、机组责任和适用性。
- 本路由只保存短术语和抽象句式，不保存或重构任何完整检查单。
- 同一主修订号不代表所有运营人增补页、有效页日期或版权文本逐项一致；只有实际核对到同章节、同对象的条目才可标记“已对齐”。
- QRH 的命令式文体不得用于强化 FCTM、法规或事故调查中的建议、可能性和证据强度。
- 固定驾驶舱标签、灯名、模式名和缩写原则上保留英文；目标状态的中文表达服从受控双语对照和辨识需要。

## 通用句法控制

| English pattern | 中文框架 | 控制点 |
|---|---|---|
| Condition: X | 状况：X | 仅用于检查单字段，不把普通 condition 全部译为“状况” |
| Objective: X | 目的：X | 保留其对预期结果或步骤理由的说明作用 |
| Choose one: | 选其一： | 保留所有并列分支及其结束范围 |
| If X: do Y | 如果 X：执行 Y | 条件只支配原文覆盖的动作或分支 |
| When X: do Y | 当 X 时：执行 Y | 不把时间／状态触发改成假设 |
| As conditions allow, do X | 情况允许时，执行 X | 不省略条件或移动到错误动作 |
| Go to step X | 转阅第 X 步 | 保留目标和方向，不译成一般阅读建议 |
| Continue with step X | 继续执行第 X 步 | 与转阅到另一位置区分 |
| Do not accomplish X | 不要完成 X | 不擅自升级为“不得”，也不弱化否定 |
| Checklist Complete | 检查单完成 | 表示完成状态，不改写成新增动作 |
| Checklist Complete Except Deferred Items | 除延迟项目外，检查单完成 | 必须保留例外范围 |
| Continued on next page | 下页续 | 保持续页对象清楚 |

## 使用前核对

1. 这是 QRH 检查单语言、FCOM 程序语言，还是 FCTM 训练叙述；
2. 控制件名称、动作和目标状态是否分别保留；
3. 条件、分支、否定、延迟项和完成范围是否完整；
4. verify、confirm、check 是否按对象和机组协同含义处理；
5. 是否误把短术语拼接成来源中不存在的程序。
