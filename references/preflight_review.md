# 初始翻译方案审核

正式航空技术资料在全文翻译前先完成本审核。目标是让用户先确认技术用语、歧义处理和版式路线；这不是全文试译，也不能保证发现执行阶段才会显现的所有问题。

## 触发与停止点

- 默认触发：完整 PDF、技术通告、训练或运行手册、事故报告，以及包含安全关键数字、图表、警告或复杂版式的材料。
- 用户明确说“直接翻译／无需初始方案确认”时可跳过本关口；终稿前确认仍保留。
- 提交《初始翻译方案》后必须停止。只有用户明确确认后才可翻译全文或生成正式 DOCX；“没有回复”不构成确认。
- 若发现关键页缺失、无法识别、适用性不明或授权范围不足，报告阻断项，不提交假定可执行的方案。

## 阅读范围

形成方案前应阅读完整材料，至少完成全文文本抽取或 OCR、全部页面缩略图检查，以及首页、修订记录、目录、适用性、警告、图表密集页和结尾页的原尺寸复核。不得只看封面或若干抽样页就宣称已掌握全文结构。

## 《初始翻译方案》内容

### 1. 材料身份与边界

- 文件、标题、正式编号、修订号、日期、页数和页面尺寸；
- 机型与正式适用性字段；正文建议范围不得提升为正式适用性；
- 文本可提取性、扫描质量、缺页、重复页或不可辨内容；
- 版权、专有和出口管制标识及已知授权边界；
- 现行性结论，以及只能由制造商受控渠道或文件所有方确认的事项。

逐项标记“已确认／合理推测／无法验证”，不得把文件名或 PDF 元数据单独当作正式编号、版次或授权证据。

### 2. 翻译目标与事实来源

- 说明用途、读者、是否打印、输出格式和页面尺寸；
- 指明英文技术事实来源，以及已有中文译稿、双语资料和术语库各自的角色；
- 说明原文文体：训练指导、运行程序、法规、事故调查或技术说明；FCTM 风格不能覆盖其他文体的法律或证据强度。

### 3. 专业术语预审

只列会影响全文一致性、飞行员理解或安全含义的真实问题，使用：

`编号｜原文术语／短语｜建议译法｜备选译法｜语境与歧义｜把握度｜建议理由｜影响范围`

- 包括多种常见译法、同词多义、容易混淆的部件／事件、动作／状态和能力／效果；
- 对 `may/can/should/must`、否定、条件、程度和范围的高风险表达单列；
- 给出可直接采用的建议，不把未经对照的推测写成已确认标准；
- 不把所有普通词汇堆入审核表。无须用户决定的高把握度条目放在信息性摘要中。

### 4. 句法、歧义和疑似错误

- 列出动作主体、指代、并列范围、条件覆盖范围或因果关系可能有两种理解的句子；
- 对疑似错字、错号、单位或交叉引用提出“照译并加译注”的建议，不静默修正；
- 如需确认整体语气，可提供少量代表性试译。试译只覆盖能验证风格的短段，不提前翻译全文。

### 5. 版式和图表路线

- 单栏／双栏、A4／Letter、页边距、字体和黑白／彩色路线；
- 图片直接提取或整页裁切、图内英文对照方式；
- 表格重建、保留原图或横向页面的选择；
- 目录、页眉页脚、脚注、警告框和交叉引用的处理；
- 预计页数变化、图位变化、无法像素级复刻的部分和打印影响。

### 6. 执行与 QA

- 分章翻译和英中复核方式；
- 数字、单位、否定、条件、情态、警告等级和图表编号检查；
- DOCX 全页渲染与视觉检查；
- 执行阶段新发现的问题将进入终稿前确认，不由译者静默决定。

## 用户回复方式

所有待决定事项都应带建议选项，使用户可以回复“全部按建议执行”，也可以只修改指定编号。已确认选择形成当前任务约束；执行阶段不得无提示改变。
